# Le vocabulaire de ceux qui voient avant que ça pète

Ce grimoire couvre tout le module 26. Pas un résumé, le bagage complet : si t'arrives pas à expliquer un terme ici à quelqu'un d'autre, retourne à la leçon avant d'avancer.

| Terme                          | Définition                                                                                                                         | Code                                                                  | Analogies                                                                                                                                                                                                    |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ / meme mecanique cote football : le staff repete jusqu'a ce que la tactique tienne sans le tableau |
| Structured logging             | Logguer en JSON avec des champs fixes et cherchables, plutôt qu'en phrase humaine libre                                            | `logger.info({ event: 'order_created', orderId })`                    | un rapport de mission Akatsuki avec des champs précis (cible, statut, lieu) plutôt qu'un récit oral vague / une fiche de match standardisée plutôt qu'un commentaire improvisé                               |
| Log level                      | Niveau de gravité d'un log : DEBUG, INFO, WARN, ERROR, FATAL, qui détermine combien d'attention il mérite                          | `logger.error({ event: 'payment_failed' })`                           | le code couleur d'alerte chez Rick : vert, jaune, rouge, jamais le même traitement / la gravité d'une carte au foot : avertissement vs exclusion                                                             |
| Correlation ID                 | Identifiant unique attaché à tous les logs d'une même requête, pour les relier à travers plusieurs services                        | `requestId: crypto.randomUUID()` propagé dans chaque log              | le numéro de dossier qui suit un prisonnier de Fox River à travers chaque service de la prison / le matricule qui suit un transfert de joueur dans chaque étape administrative                               |
| Redaction                      | Masquage volontaire d'une donnée sensible avant qu'elle n'atteigne un log                                                          | `password: '[REDACTED]'`                                              | T-Bag qui planque ses vraies intentions derrière un masque de politesse / un artiste trapsoul qui floute certains couplets avant la diffusion radio                                                          |
| Distributed tracing            | Traçage distribué : découpe une requête en spans organisés en arbre pour voir où le temps a été perdu à travers plusieurs services | `traceId` partagé, `spanId` + `parentSpanId` par étape                | la chronologie complète d'une mission Akatsuki, qui montre combien de temps chaque membre a passé sur sa partie / le décompte précis du temps de possession de chaque joueur sur une seule action            |
| Span                           | Segment de temps mesuré dans une trace, avec un nom, un début, une fin, et un parent                                               | `{ spanId, parentSpanId, traceId, duration }`                         | une étape précise du plan d'évasion de Michael, chronométrée et reliée aux étapes précédentes / une phase de jeu chronométrée dans une séquence de but                                                       |
| Waterfall (cascade)            | Représentation visuelle d'une trace, en barres empilées, qui montre la durée de chaque span dans le temps                          | graphique en barres horizontales décalées selon le `startTime`        | le déroulé minute par minute d'un combat de Garo contre un Horror / le timing exact d'une action de but décomposée touche par touche                                                                         |
| Propagation de contexte        | Le fait de transmettre le `traceId` d'un service à l'autre via les headers HTTP, pour garder une trace continue                    | header `traceparent` lu et renvoyé par chaque service                 | le message radio relayé de Chevalier en Chevalier sans jamais le perdre en route / la passe qui garde le ballon dans l'équipe sans jamais le céder à l'adversaire                                            |
| Sampling                       | Stratégie qui décide quelle proportion des requêtes sera tracée en détail, pour limiter le coût                                    | `if (hasError) return true; return Math.random() < 0.01`              | la sécurité de Fox River qui fouille systématiquement les suspects et seulement 1% des visiteurs au hasard / le contrôle antidopage qui cible les suspects et un échantillon aléatoire                       |
| Counter                        | Type de métrique qui ne fait que monter, jamais redescendre                                                                        | `totalRequests++`                                                     | le compteur de victimes dans Walking Dead, jamais remis à zéro / le nombre total de buts marqués sur une carrière                                                                                            |
| Gauge                          | Type de métrique qui monte et descend librement, reflet de l'état présent                                                          | `activeConnections++` puis `--`                                       | le nombre de survivants vivants dans le camp à un instant donné / le nombre de joueurs encore sur le terrain en ce moment                                                                                    |
| Histogram                      | Type de métrique qui capture une distribution complète de valeurs pour calculer des percentiles                                    | `httpDurationHistogram.observe(durationMs)`                           | la répartition des temps de passage de chaque coureur d'un marathon, pas juste le temps moyen / la distribution des notes Ballon d'Or, pas juste la moyenne                                                  |
| Percentile (P50, P95, P99)     | Valeur sous laquelle se trouve X% des observations : le P99 montre ce que vit le pire 1% des cas                                   | `P99 = 4000ms` même si la moyenne reste à 80ms                        | le pire combat vécu par 1% des Chevaliers, caché derrière une moyenne de combats faciles / la pire performance vécue par 1% des supporters un soir de défaite, invisible dans les stats globales             |
| Golden signals                 | Les 4 métriques essentielles d'un système : latency, traffic, errors, saturation                                                   | dashboard minimal : durée, volume, taux d'échec, charge ressources    | les 4 jauges vitales qu'un Chevalier checke avant un combat : énergie, position ennemie, dégâts, temps restant / les 4 stats de base d'un joueur avant un match : forme, minutes jouées, blessures, fatigue  |
| Alert fatigue                  | Fatigue d'alerte : à force de fausses alertes, l'équipe finit par ignorer même les vraies                                          | seuil sans durée minimale → des dizaines d'alertes par nuit, ignorées | un système d'alarme dans le camp qui sonne pour chaque écureuil, plus personne ne réagit même pour un vrai zombie / un arbitre qui siffle pour chaque contact, plus personne ne respecte le sifflet à la fin |
| Sentry (error tracking)        | Outil qui capture chaque exception en prod avec sa stack trace et son contexte complet                                             | `Sentry.captureException(err)`                                        | le dossier complet d'un prisonnier à Fox River : pas juste son nom, tout son passif et son contexte / la fiche scout complète d'un joueur, pas juste son nom sur une liste                                   |
| Fingerprinting (regroupement)  | Mécanisme qui regroupe les occurrences similaires d'une même erreur en une seule entrée                                            | `fingerprint: ['payment-timeout', route]`                             | regrouper toutes les évasions ratées par la même cause sous un seul dossier, pas un dossier par tentative / regrouper tous les buts encaissés par la même faille tactique sous une seule analyse             |
| Breadcrumbs                    | Fil des actions effectuées par l'shinobi juste avant qu'une erreur survienne, capturé automatiquement                          | actions menant au crash, listées chronologiquement                    | les indices que Daryl suit à la trace pour reconstituer ce qui s'est passé avant l'attaque / les images au ralenti qui montrent chaque étape avant un carton rouge                                           |
| Feature flag                   | Interrupteur de fonctionnalité qui permet d'activer ou désactiver du code en prod sans redéployer                                  | `if (flags.isEnabled('new-checkout', userId))`                        | l'interrupteur secret que Michael actionne pour ouvrir ou fermer un passage sans tout reconstruire / un coach qui change de système tactique en cours de match sans changer l'effectif                       |
| Heap snapshot                  | Photo de l'état de la mémoire prise à chaud, sans arrêter le process, pour traquer une fuite mémoire                               | `v8.getHeapSnapshot()` écrit sur disque pendant que le process tourne | une photo aérienne du camp prise en plein mouvement, sans interrompre les gardes / un relevé GPS pris en plein match sans arrêter le jeu                                                                     |
| Canary deployment              | Déploiement progressif d'une nouvelle version sur un petit pourcentage d'shinobis avant la généralisation                      | `1% --> surveillance --> 10% --> 50% --> 100%`                        | envoyer un seul éclaireur avant le groupe entier de Walking Dead / tester un joueur en amical avant de le titulariser en match officiel                                                                      |
| MTTR (mean time to resolution) | Temps moyen entre la détection d'un incident et sa résolution complète                                                             | réduit par logs préparés, feature flags, et dashboards clairs         | le temps moyen qu'il faut à Daryl pour neutraliser une menace une fois repérée / le temps moyen de réaction d'une défense face à une attaque rapide                                                          |
