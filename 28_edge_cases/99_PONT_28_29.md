# PONT 28 -> 29 : edge cases -> agents autonomes

Temps ~15 min

## POURQUOI CE PONT

Tu viens d'apaiser ta peur des edge cases. Le module 29 va te demander de
laisser un agent IA décider à ta place. C'est **des edge cases au carré** :
non seulement le cas rare peut arriver, mais un agent peut *inventer* un cas
qui n'existait pas.

## 3 QUESTIONS À TE POSER AVANT DE DÉLÉGUER

1. **Que se passe-t-il si l'agent choisit l'action qui casse mon invariant ?**
   Si tu ne peux pas répondre, tu ne peux pas déléguer.
2. **Quelle est la surface d'action de l'agent ?** (fichiers, réseau, secrets)
   Un agent qui peut tout faire est un edge case ambulant.
3. **Comment j'attrape en prod que l'agent a fait un edge case ?**
   Log structuré + trace + rejeu déterministe. Sans ça, tu n'as pas d'obs, tu as un rite.

## POURQUOI CE N'EST PAS UN MODULE
Un pont, pas un module : tu passes, tu prends conscience, tu ouvres 29.
