# 00_why_getting_started.md
Temps de lecture ~3 min

> Pourquoi ce module existe.

Tu ouvres MyFunnyJS, tu n'as jamais installé Node, jamais lancé une commande shell, jamais fait un `git init`. Ce module te met en état de marche : Node, shell, git, npm, hygiène minimale. Rien de JS ici. Juste les bases pour que la suite tienne debout.

Si tu sautes ce module, la première leçon de `01_fundamentals` te renverra ici en boitant. Autant venir droit.

## Ce que tu sauras à la fin
- Installer et vérifier Node 20.
- Ouvrir un terminal, naviguer, éditer un fichier.
- Faire un commit git propre.
- Distinguer npm/pnpm/bun.
- Ne pas fuiter tes clefs.

## Ordre de lecture
`01_install` -> `02_shell_survival` -> `03_git_101` -> `04_package_managers` -> `05_devsec_perso`.
