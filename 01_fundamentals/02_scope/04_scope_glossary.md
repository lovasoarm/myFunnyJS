## SCOPE GLOSSARY : LES MOTS QUE TU DOIS MAÎTRISER

Si tu ne comprends pas ces mots, tu ne comprends pas vraiment
comment JavaScript exécute ton code.
Le scope détermine :
QUI peut accéder à une variable
ET
OÙ cette variable existe dans le programme.

---

| Termes | Définitions | Codes | Analogies |
|---|---|---|---|
| Scope | Zone dans laquelle une variable est accessible | `let x = 10;` <br> `function fn() { console.log(x); }` <br> `fn(); // 10` | Une maison avec des pièces : une variable dans une pièce n'existe pas dans une autre / Un badge d'accès en entreprise : tu entres seulement là où ton badge fonctionne |
| Global Scope | Environnement principal du programme : variables accessibles presque partout | `let hero = "Link";` <br> `function show() { console.log(hero); }` <br> `show(); // Link` | Le couloir principal de l'immeuble : tout le monde y passe / La salle commune d'une auberge de jeunesse : accessible à tous les résidents |
| Local Scope | Scope limité à une fonction : la variable n'existe que dans cette fonction | `function fn() { let secret = "hidden"; }` <br> `fn();` <br> `console.log(secret); // ReferenceError` | Ta chambre d'hôtel : personne d'autre n'y entre / Le bureau d'un employé : ses affaires restent dans son bureau |
| Block Scope | Scope créé par un bloc `{}` avec `let` ou `const` | `if (true) { let potion = "Health"; console.log(potion); }` <br> `console.log(potion); // ReferenceError` <br> `// var ignorerait ce bloc` | Un casier de vestiaire : ce qui est dedans reste dedans / Une salle de réunion réservée : ce qui s'y dit ne sort pas |
| Lexical Scope | Le scope dépend de l'endroit où la fonction est **écrite**, pas où elle est **appelée** | `let name = "Global";` <br> `function outer() { let name = "Outer"; function inner() { console.log(name); } inner(); }` <br> `outer(); // Outer` | Un enfant garde l'accent de la ville où il a grandi, peu importe où il vit maintenant / Un document garde le tampon du bureau où il a été signé, pas celui où il est lu |
| Closure | Fonction qui se souvient des variables de son environnement extérieur même après sa disparition | `function makeCounter() { let count = 0; return function() { count++; return count; }; }` <br> `const counter = makeCounter();` <br> `counter(); // 1` <br> `counter(); // 2` | Un cuisinier qui quitte un restaurant mais garde toutes ses recettes en tête / Un enfant qui part de chez ses parents mais garde les habitudes de la maison |
| Function Standalone | Fonction appelée seule, sans objet, sans `new` : `this` est global ou `undefined` en mode strict | `function alone() { console.log(this); }` <br> `alone(); // window ou undefined` <br> `// vs : user.alone() → this = user` | Quelqu'un qui parle dans le vide sans s'adresser à personne en particulier / Un livreur sans adresse de destination : il ne sait pas à qui remettre le colis |
| Execution Context | Environnement créé à chaque exécution de fonction : contient les variables, `this` et la scope chain | `function fn() { let x = 1; console.log(x); }` <br> `fn(); // nouveau contexte créé` <br> `fn(); // nouveau contexte recréé` | Une scène de théâtre qui se reconstruit à chaque acte avec ses propres décors / Un nouveau chantier ouvert avec ses propres ouvriers et matériaux à chaque fois |
| Scope Chain | Chaîne de scopes remontée par JS pour trouver une variable : actuel → parent → global | `let global = "G";` <br> `function outer() { let outer = "O"; function inner() { console.log(global, outer); } inner(); }` <br> `outer(); // G O` | Un employé qui cherche un document : bureau perso → bureau du manager → archives / Un enfant qui demande à sa mère, qui demande à la grand-mère si elle ne sait pas |
| Variable Shadowing | Variable locale qui masque une variable du scope parent avec le même nom | `let name = "Global";` <br> `function fn() { let name = "Local"; console.log(name); }` <br> `fn(); // Local` <br> `console.log(name); // Global` | Un homonyme dans la même entreprise : le local prend le dessus sur le global / Un panneau de rue local qui recouvre l'ancienne indication : l'ancien nom existe toujours mais on ne le voit plus |
| Hoisting | Déclarations de variables et fonctions déplacées en haut du scope avant exécution | `console.log(x); // undefined, pas une erreur` <br> `var x = 5;` <br> `sayHi(); // fonctionne` <br> `function sayHi() { console.log("Hi"); }` | Un maître d'hôtel qui prépare ta table avant que tu arrives / Un réalisateur qui installe les décors avant le début du tournage |
| Temporal Dead Zone (TDZ) | Zone où `let` ou `const` existe mais ne peut pas encore être utilisée avant sa déclaration | `console.log(x); // ReferenceError : TDZ` <br> `let x = 10;` <br> `console.log(x); // 10` | Une chambre d'hôtel réservée mais pas encore prête : elle existe, tu ne peux pas entrer / Un colis expédié mais pas encore livré : il est en route, tu ne peux pas l'ouvrir |
| IIFE | Fonction exécutée immédiatement après sa création pour créer un scope isolé | `(function() { let secret = "isolé"; console.log(secret); })();` <br> `console.log(secret); // ReferenceError` <br> `// rien ne fuite à l'extérieur` | Un feu d'artifice allumé et explosé aussitôt : il vit et meurt sur place / Un post-it écrit, lu et jeté dans la seconde : aucune trace, aucune fuite |
| Callback Scope | Fonction passée dans une autre fonction qui garde accès à son scope d'origine | `function outer() { let msg = "Hello"; setTimeout(function() { console.log(msg); }, 100); }` <br> `outer(); // Hello` <br> `// le callback garde accès à msg` | Un ambassadeur envoyé à l'étranger qui garde ses lois nationales en tête / Un étudiant en échange qui garde les règles de son université d'origine |
| Closure Memory Trap | Une closure garde des variables en mémoire et peut bloquer le garbage collector | `function trap() { let big = new Array(1000000); return function() { return big.length; }; }` <br> `const fn = trap();` <br> `// big reste en mémoire tant que fn existe` | Un entrepôt qui stocke des caisses dont personne ne veut mais que personne n'ose jeter / Un ex qui garde toutes tes affaires chez lui : la place est occupée, rien n'est libéré |
