| Terme | Définition courte | Analogies |
|---|---|---|
| Variable | Conteneur qui stocke une valeur en mémoire | Une boîte avec une étiquette / Un tiroir avec un post-it collé dessus |
| Primitive | Valeur simple stockée directement (`number`, `string`, `boolean`, `null`, `undefined`, `symbol`, `bigint`) | Un billet de banque que tu tiens dans la main / Un chiffre écrit sur un papier : tu le lis, tu le connais |
| Object | Structure complexe : la variable stocke une référence, pas la valeur directement | Un ticket de vestiaire : tu as l'adresse, pas l'objet / Un lien vers un Google Doc : le fichier est ailleurs |
| Reference | Adresse mémoire vers laquelle pointe une variable | Les coordonnées GPS d'une maison / Le numéro de chambre dans un hôtel |
| Mutation | Modifier une valeur existante : toutes les références vers cet objet sont affectées | Repeindre la maison : tout le monde qui a l'adresse voit le changement / Modifier un Google Doc partagé : tout le monde voit la nouvelle version |
| Shallow Copy | Copie de la première couche seulement : les objets imbriqués restent liés | Photocopier la couverture d'un livre, pas les pages / Dupliquer un dossier sans copier les fichiers qu'il contient |
| Deep Copy | Copie complète de toute la structure, niveaux imbriqués inclus | Imprimer l'intégralité du livre, page par page / Cloner une clé USB avec tout son contenu |
