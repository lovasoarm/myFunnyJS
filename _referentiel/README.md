# _referentiel : le referentiel pedagogique

Ce dossier contient les **règles du jeu** du curriculum MyFunnyJS Thor Edition.
Il n'est **pas** une lecon. Il est le **document contractuel** qui définit :

- ce que tout module doit produire (Parties A a V),
- le moteur d'audit JARVIS (Partie W),
- les compétences visées par le diplômé (`competences.md`).

## Quand y revenir ?

- Avant de rediger une lecon : verifier les regles Partie B (ton, mots interdits, analogies).
- Avant de creer un mini-projet : verifier Partie I (gate securite) et Partie J (verification_pack).
- Avant de proposer une PR : verifier Partie H (structure) et Partie N (reactivation).

## Fichiers

- `competences.md` : matrice des competences Thor.

Le referentiel n'a pas de `00_why_referentiel.md` : sa raison d'etre est **d'etre le referentiel**, pas de l'expliquer.
