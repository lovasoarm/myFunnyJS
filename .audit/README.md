# .audit — journal d'audit interne

Ce dossier regroupe les livrables du processus d'audit interne du curriculum.
Il n'est PAS destiné à l'apprenant : ni prérequis, ni exercice, ni lecture
obligatoire.

## Contenu

- `CORRECTIONS_APPLIQUEES.md` : journal des corrections cumulées.
- `CORRECTIONS_AUDIT_W.md` : passe d'audit W (historique).
- `CORRECTIONS_AUDIT_10_10.md` : passe d'audit visant la note 10/10.
- `CORRECTIONS_AUDIT_FINAL.md` : passe finale avant publication.
- `DEPENDENCY_LEDGER.md` : registre des dépendances versionnées et de leurs
  contraintes (Node, packages, décisions de non-mise à jour).
- `README.md` : ce fichier.

Ajoute une entrée à cette liste dès que tu déposes un nouveau document ici.

## Convention

Ce dossier est marqué `stability: perissable` : il documente un état
temporel, pas un savoir. Rien de ce qu'il contient n'est prérequis pour
comprendre le curriculum.

Si tu es apprenant, retourne à `START_HERE.md` à la racine.
