## CONTEXTE

Une revue IA de ton dépôt donne un avis instantané ; savoir trier ses remarques est la compétence réelle.

## APPLICATION

- Soumets un fichier réel du portfolio à une revue IA.
- Classe chaque remarque : juste et utile / juste mais sans intérêt ici / fausse.
- Applique uniquement la première catégorie et documente une remarque rejetée avec ton argument.

## Vérification

Sur quelle remarque as-tu eu raison contre l'IA, et sur quoi t'appuies-tu pour l'affirmer ?

##Tu arbitres une revue de code

Tu passes de « consommateur d'IA » à relecteur de l'IA. Commit les corrections retenues.
