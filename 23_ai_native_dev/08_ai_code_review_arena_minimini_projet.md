## TYPE

Micro-drill

## Niveau

🗸 Avancé

## CONTEXTE

Une revue IA de ton dépôt donne un avis instantané ; savoir trier ses remarques est la compétence réelle.

## APPLICATION

- Soumets un fichier réel du portfolio à une revue IA.
- Rends un verdict pour chaque remarque : VALIDÉ / À VÉRIFIER / REJETÉ.
- Pour chaque remarque, note : problème identifié, preuve dans le code, action, raison du verdict.
- Applique uniquement les remarques VALIDÉES et documente une remarque REJETÉE avec ton argument.

## Critère de réussite

- [ ] Soumets un fichier réel du portfolio à une revue IA.
- [ ] Rends un verdict pour chaque remarque.
- [ ] Je peux expliquer le résultat obtenu sans relire le cours.

## Vérification

Sur quelle remarque as-tu eu raison contre l'IA, et sur quoi t'appuies-tu pour l'affirmer ?

## Preuve à conserver

Après l'expérience, conserve :

- le résultat observé ;
- l'explication ;
- la règle générale que tu en tires ;
- une limite ou une exception connue.

## Ce que tu viens de démontrer

Dans ce scénario, tu as vérifié que : tu arbitres une revue de code.

Tu passes de « consommateur d'IA » à relecteur de l'IA. Commit les corrections retenues.
