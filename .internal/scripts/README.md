# scripts/ : outils de maintenance

**Ce dossier n'est PAS pédagogique. Ignore-le en tant qu'apprenant.**

Il contient les scripts internes utilisés par les mainteneurs de MyFunnyJS pour packager, releaser et vérifier le repo. Rien ici n'est destiné à être lu, exécuté, ou étudié par un apprenant.

- `pack_release.sh` : script de packaging d'une release du repo. Aucune valeur pédagogique.

Ce dossier est listé dans `.gitignore` racine pour ne pas polluer tes exercices. Il reste physiquement présent dans le repo source pour les mainteneurs, mais tu peux le considérer comme invisible.
