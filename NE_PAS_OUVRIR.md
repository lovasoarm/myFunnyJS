# NE PAS OUVRIR

Trois dossiers n'ont aucune valeur pédagogique pour toi :
- `.tools/verification_pack/` : les scripts de vérification (CI, drills)
  qui font tourner les `verify.sh` appelés depuis les exercices.
- `.audit/` : modèle de référence interne (`DEPENDENCY_LEDGER.md`).
- `scripts/` : outils de maintenance du repo (lint, release).

Tu peux totalement les ignorer en tant qu'apprenant.

Si tu es curieux : ce sont les mécanismes qui garantissent que les exercices
sont réellement passés (`verify.sh` reste binaire : ça passe ou ça passe pas).
Pour apprendre JS/prod : reste dans les modules numérotés `01_` -> `32_` et
`30_mini_projects/`.
